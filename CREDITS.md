# Credits

## Game assets

Ships, ship parts, projectiles, effects, tiles, HUD/menu sprites, sprite sheets, reference images, the Jungle Gaming logo
and the WAV sound files in `public/assets/` were provided with the challenge brief and are used as the visual base of the game.

### author file, source URL and license text ( Assets and Original Project)

Jungle Gaming.

Modifications made by this project: only the retina PNGs (`public/assets/png/retina/`) are used by the game; the 1× PNGs
and the vector sources were removed from the repository to reduce its size. No image was edited.

## Fonts

No custom web fonts are used; the interface uses the system font stack (`system-ui, sans-serif`).

## Libraries

React, PixiJS, TanStack Query, Axios, Zustand, MSW, Playwright, Vite, TypeScript and ESLint, each under its own open-source license (see `package.json` and `package-lock.json`).
